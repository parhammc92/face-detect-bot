# 🤖 my bot — تشخیص چهره با OpenCV

تمرین آموزشی: پیدا کردن چهره در عکس با مدل کلاسیک **Haar Cascade** (تشخیص چهره‌ی جلو، ۲۴×۲۴ AdaBoost از Rainer Lienhart).

## 🔍 چطور کار می‌کند؟
1. مدل `model.xml` لود می‌شود (هزاران ویژگی Haar آماده‌شده با نایاب‌ریزی آدابوست)
2. عکس به سیاه‌وسفید تبدیل می‌شود (مدل روی خاکستری کار می‌کند)
3. `detectMultiScale` در چند مقیاس پنجره می‌کشد و چهره را می‌یابد
4. دور هر چهره مستطیل سبز + برچسب «Face» کشیده می‌شود
5. نتیجه در `result.jpg` ذخیره می‌شود

## 🚀 اجرا
```bash
python -m venv .venv
.venv/bin/pip install "opencv-python<5"   # نسخه‌ی 4.x لازم است!
.venv/bin/python bot.py
```

> ⚠️ **نکته:** OpenCV نسخه‌ی ۵ کلاس `CascadeClassifier` را حذف کرده است —
> برای این مدل حتماً `opencv-python<5` نصب کنید.
